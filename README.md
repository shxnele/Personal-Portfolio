# Shannel Igana, Portfolio

Open `index.html` in a browser. No build step needed.

## Before publishing, edit `src/js/script.js`
Replace the placeholder email and social links in the `PROFILE` block at the top.
They update the contact section, the home icons and the contact form automatically.

## Structure
- `index.html`: Home, About & Skills, Projects, Case Study, Contact
- `src/css/styles.css`: responsive styling
- `src/js/script.js`: menu, scroll highlighting, contact form, profile settings
- `src/assets/icons/favicon.svg`: custom portfolio favicon
- `images/profile.jpg`: optimized portrait
- `project/`: source code for the case-study project (run `python lab.py` from inside that folder)
